I'm **Hamza**, a Computer Science student at GUtech in Oman. I like turning an idea into something you can actually use—from a single interaction to a complete product.

Right now, most of my attention is on **Vitrine**: a collection of React components with a point of view.

<br>

<a href="https://tryvitrine.dev"><img src="assets/vitrine.svg" width="100%" alt="01 — Vitrine. Kept under glass. Open-source React components with memorable interactions, source, design prompts, portfolio recipes and agent skills." /></a>

A filter that shows what it removed. A paragraph whose numbers you can drag. An undo history that keeps its branches. **Vitrine is built around mechanisms worth using.**

Explore the demos, copy the files, or adapt the design prompts with your coding agent. Free and open source, with portfolio recipes and agent skills to help assemble the pieces.

**React + TypeScript · CSS + Tailwind where useful · No animation libraries**
